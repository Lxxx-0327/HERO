# HERO
**HERO** (High-rEsolution visual token eaRly drOpping) is an efficient and training-free framework for visual token compression in High-Resolution Large Vision-Language Models (HR-LVLMs). By integrating a content-adaptive token budget allocation mechanism and a function-aware token selection strategy, HERO significantly reduces computational and memory overheads while maintaining, or even improving, model performance on diverse vision-language tasks.
